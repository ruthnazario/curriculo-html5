# 📄 Currículo Web — HTML5

Projeto desenvolvido como atividade acadêmica da graduação em **Análise e Desenvolvimento de Sistemas**, com o objetivo de criar uma página web para apresentação de um currículo profissional.

## 🎯 Objetivo

Desenvolver um currículo em formato de página web, aplicando conceitos fundamentais de desenvolvimento Front-End e estruturação de documentos HTML5.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3

## 📋 Conteúdo

A página apresenta informações como:

* Dados de contato
* Objetivo profissional
* Formação acadêmica
* Experiência profissional
* Cursos e certificações
* Habilidades e conhecimentos técnicos
